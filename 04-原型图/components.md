# 云栖露营地 · 组件规范

所有尺寸单位 px，色值引用 `design-system.md`。实现阶段一一对应 Element Plus 组件，不自造控件。

## 1. 按钮 Button

| 类型 | 高度 | 内边距 | 背景 | 描边 | 文字 |
|---|---|---|---|---|---|
| 主按钮 primary | 34 | 0 14 | `#1F2937` | 同背景 | `#fff` |
| 次按钮 default | 34 | 0 14 | `#fff` | `#DDE3EA` | `#1B2430` |
| 幽灵 ghost | 34 | 0 14 | `#EAF0F4` | `#C6D3DC` | `#1F2937` |
| 危险 danger | 34 | 0 14 | `#fff` | `#E7C4C7` | `#B3261E` |
| 小号 sm | 26 | 0 10 | 同上 | 同上 | 12px |

- 圆角 6，字号 13，行内按钮组间距 8
- 主按钮每屏最多 2 个（一个主操作 + 一个新增）
- 禁用态：背景 `#EDF0F4`，文字 `#9AA5B1`，不降透明度

## 2. 输入 Input / Select

- 高度 34，圆角 6，描边 `#DDE3EA`，内边距 0 10
- 聚焦：描边 `#2F6B8A` + 外圈 `0 0 0 3px rgba(47,107,138,.12)`
- 表单标签：右对齐，宽 110，与控件间距 10，字号 13 次要色
- 单列输入宽 360–520；**搜索下拉宽 180–240**（小于 160 会截断「草坪帐篷位」这类值）
- 多行文本：内边距 8 10，行高 20，可纵向 resize
- 校验失败：描边 `#B3261E`，下方 12px 红色说明，不弹 toast

## 3. 表格 Table

- 表头：背景 `#F0F3F7`，文字 13/500 次要色，下描边 1px
- 单元格：内边距 11 12，下描边 `#EDF0F4`，字号 13
- 行悬停 `#FAFBFC`
- **表头不写死宽度**，只设最小宽度，允许横向滚动；编号、状态、日期、操作列 `white-space: nowrap`
- 金额列右对齐 + `tabular-nums`；状态列统一用标签组件
- 图片列：40×30，圆角 3，与名称同行，间距 8
- 分页：右对齐，「共 N 条 + 每页条数(10/20/50) + 页码」，高 26

## 4. 卡片 Card

- 背景白，描边 1，圆角 8，内边距 16 18
- 标题区：16/600，下方间距 12，右侧可放次要说明（12px 次要色）
- 卡片之间间距 14–16，不使用阴影分隔

## 5. 标签 Tag / 状态

高 22，圆角 4，内边距 1 8，字号 12，1px 描边。五套语义色见设计系统第 2 节。

营位状态与标签对应关系（固定，不随页面变化）：

| 状态 | 标签色 | 圆点色 |
|---|---|---|
| 可预订 | t-green | `#2E7D5B` |
| 已预留 / 已确认 | t-blue | `#2F6B8A` |
| 已入住 | t-blue（深） | `#1F4A63` |
| 待清洁 / 待备货 | t-amber | `#9A6B1F` |
| 维修中 / 停用 / 损坏 | t-red | `#B3261E` |
| 已结算 / 已取消 | t-green / t-gray | — |

## 6. 弹窗与抽屉

- 抽屉：宽 440，右侧滑出，上方 16/600 标题 + 单据摘要，底部按钮右对齐
- 遮罩：`rgba(27,36,48,.28)`
- 二次确认弹窗：宽 420，标题 + 影响说明 + 取消/确定；危险操作确定按钮用 `#B3261E`
- 审批、流转、分配菜单一律用抽屉，不用居中大弹窗

## 7. 图表 Chart

- 卡片内边距 12 14，标题 13/500 + 右侧单位说明 12px
- 柱图柱宽自适应，间距 10，圆角 3 3 0 0
- 环形图直径 104，环宽 24，中心留白
- 图例 12px，色块 8×8 圆角 2，间距 14
- 看板图表卡固定高 300（2 行），内部 `overflow: hidden`，禁止把整页撑出 900 视口
- 图表可点击，跳转到带对应筛选条件的列表

## 8. 时间轴 Timeline

- 左描边 1px，节点 9×9 圆，白描边 2
- 条目间距 14，标题 13/500，时间 12 次要色
- 用于预约变更、隐患整改、结算留痕、创新模块计算历史

## 9. 分值条 Score Row

用于创新模块 6 因子展示：

- 栅格 `130px 1fr 56px`，行距 9
- 轨道高 8，圆角 4，填充色 `#2F6B8A`
- 右侧分值 13/500，主色，右对齐等宽数字
- 因子名后可附权重 `(20%)`，用 12px 次要色

## 10. 上传 Uploader

- 列表态：150×104 缩略图 + 下方 12px 说明
- 空位：虚线描边 1 + 圆角 6 + 居中「+ 上传照片」
- 限制提示写在区块上方：格式、单张大小、数量上限
- **不允许出现手填 URL 的输入框**；上传后回填相对路径 `/uploads/seed/<实体>/NN.jpg`
- 删除需二次确认，已提交单据的附件只允许追加不允许物理删除

## 11. 移动端组件

- 设备框 390×844，头部 52 主色，底部操作条 58
- 列表项：白色卡片 8 圆角，标题 13/600 + 状态标签，副行 12 次要色
- 分段切换（待执行/进行中/已完成）：胶囊 14 圆角，选中态主色底白字
- 表格在 <768px 转卡片，只保留编号、状态、时间、负责人
