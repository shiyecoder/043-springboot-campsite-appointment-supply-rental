# 云栖露营地 · 设计系统

> 项目：露营地营位预约与物资租赁管理系统（NEW-043）
> 视觉方向按需求文档「UI 视觉与交互设计」一节执行：企业海军蓝、数据可读性优先、圆角 6–8px、阴影只用于抽屉与弹窗。

## 1. 设计定位

面向营地运营方的内部业务系统。使用者一天内要在预约、入住、备货、巡检之间来回切换，因此**信息密度高、状态辨识快、操作路径短**是三条硬标准。不做巨幅英文口号、装饰光效、悬浮球、大面积插画。

- 管理端：220px 左侧菜单 + 56px 顶栏 + 24px 内容边距
- 游客端（门户）：60px 顶部导航 + 1180px 居中内容容器
- 移动端（<768px）：侧栏转抽屉，表格转信息卡片，主要按钮固定安全区

## 3. 角色视觉区分

五个角色共用组件库，但侧边栏底色与头像色阶不同，进入系统第一眼即可区分：

| 角色 | 侧栏底色 | 说明 |
|---|---|---|
| 运营经理 | `#1F2937` | 完整菜单 17 项 |
| 前台人员 | `#24455C` | 预约/入住/结算为主 |
| 仓库人员 | `#2A504A` | 物资/备货/归还为主 |
| 系统管理员 | `#1B2430` | 用户、角色、规则 |
| 游客 | 门户浅色 | 无侧边栏，顶部导航 |

## 4. 字体与数字

- 字族：`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`
- 阶梯：H1 20/28、H2 16/24、正文 14/22、辅助 13/22、说明 12/20
- 表格正文 13px，表头 13px / 500 字重
- **数字列统一 `font-variant-numeric: tabular-nums`**，金额、数量、评分、时长对齐看齐
- KPI 数值 26/34，单位用 `small` 降级到 13px 次要色

## 5. 间距与圆角

- 间距基数 4px，常用 8 / 12 / 16 / 24
- 卡片内边距 16–18px，卡片间距 14–16px
- 圆角：卡片与容器 8px，按钮输入框 6px，标签 4px，胶囊 20px
- 阴影仅两处：抽屉 `-8px 0 24px rgba(27,36,48,.12)`，移动端原型 `0 8px 28px rgba(27,36,48,.14)`
- 卡片描边 `1px solid #DDE3EA`，不用阴影代替描边

## 6. 关键页面结构

| 页面 | 结构 |
|---|---|
| 经营看板 | 6 KPI + 6 图表，2 行 × 3 列，行高 300px，1440×900 一屏不滚动 |
| 营位地图 | 条件区 + 业务摘要 + 营位网格（6 列），状态用左侧色块 + 圆点 + 文字 |
| 预约日历 | 7 列月历，格内事件条最多 2 条，超出折叠 |
| 联合可用性 | 输入区 + 总分与 6 因子分条 + 影响因素 / 未满足条件 / 替代组合 + 人工调整与留痕 |
| 退营结算 | 验收项 + 归还明细 + 费用汇总 + 右侧结算单（收款方式 + 人工调整原因） |
| 门户首页 | 渐变 Hero（含 3 个统计）+ 筛选条 + 营位卡片 3 列 + 右栏须知与我的预约 |

## 7. 交互规则

- 表格行内最多「查看 + 2 个高频操作」，其余进「更多」
- 危险操作红色描边按钮 + 二次确认；普通取消不做强提醒
- 审批与流转用抽屉，抽屉内带单据摘要（440px 宽）
- 状态流转条固定在详情页顶部，已完成/当前/未开始三态
- 空状态必须说明原因与下一步（如「当前筛选条件下无记录，清空筛选或新建预约」）
- 加载超 300ms 用表格骨架，不整页白屏

## 8. 无障碍与可用性

- 状态不只靠颜色，必须有中文标签
- 点击区域 ≥ 44px（移动端）
- 对比度：正文 `#1B2430` on `#F5F7FA` ≈ 13.8:1；次要文字 ≈ 5.6:1，均达 AA
